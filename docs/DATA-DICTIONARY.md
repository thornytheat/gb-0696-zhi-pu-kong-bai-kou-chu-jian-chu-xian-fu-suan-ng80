# 质谱字段与规则

sample_id保留前导零。kind取standard、blank、sample、control。area与internal_area为峰面积。level为标样浓度，单位支持ug/L、mg/L、ng/L；统一为ug/L。dilution必须大于0。

每批每检测项至少3个独立浓度点。最小二乘使用Decimal，分母为零拒绝；斜率非正拒绝。空白取同批同项的浓度中位数。净浓度允许为负；不能提前截零。稀释后检出限=0.05×倍数。控制样相对误差超过20%阻断。超过标曲响应范围优先于其他质控判断。

重复编号相同内容标DUPLICATE，不同内容标KEY_CONFLICT。采信包括标曲和空白，最终样品数不等于输入采信数。行数对账独立于样品结果数。

同一批次同一分析项内sample_id唯一；相同样品编号可在不同分析项或批次中复用。

## 夹持与交接

同一批次同一检测项内，按采信行的物理顺序判定夹持：样品前面须有一条标样、后面须有一条标样，
两者都来自本批本项且未被隔离。缺前标样、缺后标样或两侧都缺分别记 MISSING_BEFORE、MISSING_AFTER、MISSING_BOTH。
隔离的标样不参与夹持，换检测项或换批次也不能借用。

未夹持样品仍给出参考浓度与按稀释倍数算出的检出限，但 lod_valid=false、releasable=false，限定符保留 `<` 只表示低于检出限。
夹持状态、缺项、前后标样编号与行号、最近的前后空白一并写入结果行与导出。

交接裁决取：阻断（有阻断项或标曲失败）、可复核（全部夹持且非阻断）、先交可证实部分（部分夹持）、整批等齐（无一夹持）。

## 补测与复核

后段补测接在原序列之后，原始行一行不改，物理行号不变；补测行另记 source_line（补测文件内的行号）与 segment。
同一次补测重试不新增结果；补测失败不写入新版。

复核事件不可变：每次记录 revision、decision、scope、可证实数与未交数。
version 落后返回409；已复核结论不能被覆盖，只能追加新事件。旧版批次在补测产生子批后仍可查询，但标记为已被后续批次取代。
