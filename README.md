# 质谱空白扣除与检出限复算

环境实验室分析员使用本工具接收仪器峰面积与标曲空白，复算浓度并检查稀释与检出限制。

## 核心计算

最小二乘标曲必须满秩，空白扣除保留负值，浓度按稀释倍数复算；低于检出限保留限定符。

样品必须被同批同检测项的前后标样夹住才算已校正。序列可先跑前半段，后段到货后以补测追加；
未夹持样品保留参考值，但检出限标记无效、不可放行，页面与导出会列出缺前标样还是后标样。

## 启动

```bash
docker compose up --build -d
docker compose exec -T app pytest -q
docker compose config --quiet
```

浏览器访问 http://localhost:18210 。默认载入仓内样例。工具条可选择CSV文件运行；样例文件位于 `sample_data/instrument.csv`。重复执行同一内容复用同一批次。

勾选“作为后段补测追加”后运行，会把新内容接到当前批次之后重新计算。同一序列的补测可继续追加；
同一段补测重复提交返回已有结果，不新增批次；补测解析或计算失败时不写入新版，旧版原样保留。

## 模块

- M1 仪器接收：`/module/1`，独立计算 `POST /api/1`。
- M2 内标归一：`/module/2`，独立计算 `POST /api/2`。
- M3 标曲拟合：`/module/3`，独立计算 `POST /api/3`。
- M4 空白扣除：`/module/4`，独立计算 `POST /api/4`。
- M5 浓度复算：`/module/5`，独立计算 `POST /api/5`。
- M6 质控判定：`/module/6`，独立计算 `POST /api/6`。
- M7 结果复核：`/module/7`，独立计算 `POST /api/7`。

## 输入与输出

CSV可用UTF-8或GB18030；上传保留字符串编号和物理行号。POST `/api/run` 接收 `text` 字段。`GET /api/runs` 查询历史，`POST /api/review` 接收 id、revision、decision、scope。`POST /api/run` 可带 `parent_id` 与 `retest` 追加后段。导出按钮下载唯一证据CSV，含运行摘要、逐行夹持证据、隔离记录与复核事件。

SQLite命名卷保存运行记录与复核事件。复核须带范围：`整批` 或 `可证实部分`。存在未夹持样品时整批通过返回409，
可证实部分仅在确有可放行样品时通过；每次复核追加一条不可变事件，旧结论可查不可覆盖。版本落后返回409。
重建演示数据可更换卷名后重启。无需外部网络数据。规则定义见 `docs/DATA-DICTIONARY.md`；边界和测试对应关系见 `docs/DEPTH.md`。

## 范围

只处理仓内CSV定义，不连接生产系统。单次输入最多2MB。原始输入流式解析，业务计算阶段需容纳该文件的采信行。并非无限容量任务。
